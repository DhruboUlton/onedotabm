# OneDot ABM — Design System & Art Direction

## 1. Design Direction

The OneDot ABM website should feel:

- Modern
- Slick
- Premium
- Minimal
- Futuristic
- Editorial
- Confident
- Technology-driven
- Business-focused
- Future-proof

The provided black-background reference is a **visual and structural inspiration only**. The new website must use a **light/off-white visual system** rather than reproducing the dark theme.

Core design principle:

> Minimal surface. Strong typography. High-quality spacing. Subtle motion. Clear hierarchy.

The website should feel like a premium modern creative/technology company, not a generic digital marketing template.

---

## 2. Color System

### Primary Background

Use a warm white / off-white rather than pure white.

Suggested:

- Primary background: `#F7F7F5`
- Secondary background: `#FFFFFF`
- Soft surface: `#F0F0ED`

### Typography

Primary text should be black / near-black:

- Primary text: `#111111`
- Secondary text: `#555555`
- Muted text: `#858585`

### Borders

Use very subtle borders:

- Light border: `#E5E5E2`
- Strong border: `#D8D8D4`

### Accent

Use a restrained accent color for important interactions, CTAs, active states and small visual details.

The accent must not dominate the interface.

The overall system should remain:

**Off-white + White + Black + subtle accent**

Avoid excessive gradients and excessive colorful UI.

---

## 3. Typography

Typography should be one of the main visual features.

Use a modern sans-serif typeface with excellent display and UI readability.

Preferred direction:

- Inter
- Geist
- SF Pro-style typography
- Neue Haas Grotesk-style alternatives

### Typography hierarchy

Hero:

Very large, bold, clean display typography.

Section headings:

Large and confident, but smaller than the hero.

Body:

Clean, highly readable, moderate line height.

Labels:

Small uppercase or compact typography with increased letter spacing.

Buttons:

Medium weight, compact and clear.

Do not use too many font families.

Maximum:

**1 primary typeface + optional display treatment using the same family.**

---

## 4. Overall Layout

Use a spacious editorial layout.

Characteristics:

- Large whitespace
- Strong grid
- Asymmetric compositions where appropriate
- Large typography
- Full-width sections
- Generous horizontal margins
- Controlled content width
- Clear visual rhythm

Avoid:

- Dense card grids
- Excessive rounded cards
- Generic SaaS layouts
- Excessive shadows
- Too many floating elements
- Template-like section repetition

---

## 5. Loading Screen

The first screen should remain inspired by the provided reference.

### Concept

Off-white background.

Centered OneDot ABM logo/mark.

Minimal loading animation.

Possible sequence:

1. Logo mark appears.
2. Logo subtly scales/fades.
3. Loading indicator progresses.
4. Main website reveals with a smooth transition.

The animation should be short and elegant.

Do not make the loading screen unnecessarily long.

Target experience:

**Fast → Minimal → Premium → Transition into homepage**

# 22. Motion & Interaction

Motion should be intentional.

### Recommended

- Smooth page transitions
- Scroll reveal
- Text reveal
- Image masking
- Hover transformations
- Number counters
- Horizontal movement
- Subtle parallax
- Cursor interactions
- Magnetic buttons
- Menu transitions

### Avoid

- Excessive bouncing
- Constant movement
- Heavy 3D everywhere
- Slow transitions
- Animation that delays content
- Decorative motion without purpose

The website must remain fast.

---

- Image movement

- Active state

# 24. Responsive Design

Mobile should not simply be a compressed desktop version.

### Mobile priorities

- Large readable typography
- Strong spacing
- Easy navigation
- Thumb-friendly buttons
- Optimized images
- Reduced animation
- Simplified layouts
- Horizontal scrolling only where genuinely useful

Mobile navigation:

Menu icon → full-screen or large overlay menu.

Primary CTA should remain easily accessible.

# 28. Accessibility

The design must maintain:

- Strong text contrast
- Keyboard navigation
- Visible focus states
- Semantic HTML
- Accessible buttons
- Accessible forms
- Alt text
- Reduced-motion support
- Proper heading hierarchy

Do not sacrifice usability for visual effects.

---

# 29. Performance

The visual system must be future-proof from a performance perspective.

Priorities:

- Optimized images
- Lazy loading
- Responsive images
- Modern image formats
- Minimal JavaScript where possible
- Code splitting
- Efficient animations
- Avoid unnecessary video backgrounds
- Fast first contentful render
- SEO-friendly rendering

Animation should use performant browser properties where possible.

---

# 30. Brand Rule

The most important visual rule:

**Do not recreate the reference website.**

Use the reference for:

- Editorial composition
- Large typography
- Visual rhythm
- Navigation philosophy
- Section transitions
- Motion inspiration
- Experimental layouts

But OneDot ABM must have its own:

- Color system
- Typography
- Logo treatment
- Content
- Layouts
- Graphics
- Motion language
- Brand identity

The final experience should look like a **premium light-mode marketing + technology company**, not a light-colored copy of the black Gleamy design.
